# Weekly Project Feedback Tool — MVP Scope

## 1. Purpose
An internal tool for weekly project feedback that brings project managers and project team members into a structured weekly “round table” to review project progress, issues, and next actions.

## 2. MVP Users
- Project Managers
- Project Team Members

## 3. MVP Workflow
1. User opens the weekly feedback form.
2. One form covers all projects the user is involved in.
3. The form allows the user to drill down into each individual project.
4. User submits progress information and short notes for each relevant project.
5. Submitted feedback feeds a dashboard for project/project-team visibility.

## 4. Weekly Form

### General
- Week / reporting period
- User
- Role
- Projects involved in

### Per Project
- Project name
- Progress status
- Progress percentage / completion estimate
- Completed work
- Short notes
- Current risks / blockers
- Action items / next steps

### Simple Status
- On Track
- At Risk
- Blocked

## 5. Dashboard — MVP
The dashboard should provide a simple weekly view of:
- Projects and their current status
- Progress/completion
- Completed work
- Risks and blockers
- Action items
- Feedback from team members and project managers

## 6. MVP Principle
Keep the first version simple. The goal is to test whether structured weekly feedback improves project visibility and communication before adding more advanced functionality.

## 7. Out of Scope for MVP
- Complex performance scoring
- Anonymous feedback
- Advanced analytics
- Automated AI summaries
- Complex sprint management
- Client-facing feedback
- Extensive integrations

These can be considered after the MVP has been tested.

## 8. Future Possibilities
- Automated weekly reminders
- AI-generated weekly project summaries
- Trend analysis across weeks
- Team/project health indicators
- Action-item tracking
- Microsoft Teams integration
- Power BI integration
- Notifications for projects marked At Risk or Blocked

## 9. Success Criteria
The MVP should make it easy for a project manager to answer:
- What was completed this week?
- How far is each project?
- What is currently at risk or blocked?
- What needs attention next week?
- What are team members reporting about the project?

## 10. Initial MVP Definition
**One weekly form → multiple projects → project-level feedback → simple dashboard.**

This is the agreed starting scope. Build the smallest useful version first, test it internally, then expand based on actual usage.
